# Pequenos Momentos

## Sobre o projeto

Pequenos Momentos é uma página Web desenvolvida
no âmbito de um curso de Desenvolvimento Web Full Stack.

O projeto pretende mostrar a importância de
valorizar as pequenas coisas do dia a dia,
como a natureza, os animais e os momentos
de tranquilidade.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries

## Funcionalidades

- Menu de navegação
- Secção de apresentação
- Cartões com imagens e links externos
- Galeria de imagens
- Formulário de contacto

## Design responsivo

A página utiliza uma media query com
max-width de 768px para adaptar os cartões
a ecrãs mais pequenos.

## Como visualizar o projeto

1. Descarregar a pasta do projeto.
2. Abrir o ficheiro index.html.
3. Visualizar a página num navegador Web.

Não é necessária nenhuma instalação adicional.

## Nota

O formulário é demonstrativo e não realiza
o envio de mensagens.
